### Quién soy

No vengo del mundo gamer por casualidad: quiero construirlos. Estudio Ingeniería de Sistemas en CORHUILA y estoy usando cada materia — lógica, backend, microcontroladores — como una pieza más para llegar al desarrollo de videojuegos y experiencias interactivas.

Todavía estoy en la fase de sentar las bases. Nada de humo: los proyectos "grandes" vienen después, primero la lógica sólida.

### En qué ando

- Aprendiendo a pensar en mecánicas de juego, no solo en código
- Reforzando JavaScript y lógica de programación como puente hacia motores web (HTML5/JS)
- Metiéndole mano a microcontroladores (ESP32, MicroPython) por el gusto de hacer que las cosas *respondan*
